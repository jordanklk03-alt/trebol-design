# Trébol Design - Landing Page Corporativa

Landing page moderna y profesional para Trébol Design, agencia de diseño web y desarrollo digital.

## 🎨 Características

- ✅ Diseño moderno con tema oscuro y neón verde
- ✅ Logo verde neón prominente
- ✅ Eslogan: "Transformamos tu Visión en Realidad"
- ✅ Portfolio con 3 proyectos destacados
- ✅ Sección de servicios
- ✅ Formulario de contacto
- ✅ Completamente responsive
- ✅ Animaciones suaves
- ✅ Optimizado para SEO
- ✅ Performance alto

## 🚀 Tecnologías

- **Next.js 14** - Framework React
- **TailwindCSS** - Estilos
- **TypeScript** - Tipado
- **Lucide React** - Iconos

## 🎯 Secciones

1. **Header** - Navegación fija con logo
2. **Hero** - Sección principal con eslogan y CTA
3. **Portfolio** - 3 proyectos destacados
4. **Servicios** - 4 servicios principales
5. **Contacto** - Formulario y información
6. **Footer** - Enlaces y redes sociales

## 🛠️ Instalación

```bash
# Clonar el repositorio
git clone https://github.com/jordanklk03-alt/trebol-design.git

# Entrar al directorio
cd trebol-design

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Compilar para producción
npm run build

# Iniciar en producción
npm start
```

## 📝 Personalización

Para cambiar información:

1. **Logo/Eslogan**: Editar `components/Hero.tsx`
2. **Portfolio**: Actualizar `components/Portfolio.tsx`
3. **Contacto**: Modificar `components/Contact.tsx`
4. **Colores**: Cambiar en `tailwind.config.js`
